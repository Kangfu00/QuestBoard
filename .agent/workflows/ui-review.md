---

อ่าน `.agent/rules/design-system.md` ก่อน แล้วไล่ตรวจ:

1. **วัสดุ:** ของใหม่ทำจากภาษาวัสดุเดิม (ไม้ กระดาษ หนัง ทองเหลือง หมึก) ด้วย CSS/SVG ไม่มีภาพ/ฟอนต์/ไลบรารีใหม่
2. **สี:** ไม่มีขาว/ดำล้วน ไม่มีสีเย็น เงาเป็นน้ำตาลอุ่น สีที่ใช้ซ้ำถูกประกาศเป็น custom property สีสถานะมีข้อความหรือรูปทรงประกอบ
3. **ตัวอักษร:** ข้อความไทยใช้ Noto (ไม่ใช่ Cinzel) line-height ≥ 1.6 ไม่เพิ่ม letter-spacing ให้ภาษาไทย ขนาดอ่านบนบอร์ด ≥ 11px
4. **เลย์เอาต์:** ไม่เพิ่มแถบเมนูถาวร ใช้ตัวแปรขนาดกระดาษ (`--quest-paper-*`) ไม่ใส่ตัวเลขตรง ๆ ไม่จัดตำแหน่งของผู้ใช้ทับ z-index ไม่ขัดกับชั้นที่มีอยู่
5. **การเคลื่อนไหว (ดู `motion-and-interaction.md`):** ของติดมือไม่หน่วง ไม่ ease พิกัด; ท่าทางเหมาะกับวัสดุ (กระดาษงอ แฟ้มแข็ง); มีใบ้เป้าหมายก่อนปล่อย; ข้อมูล commit ก่อนอนิเมชัน; ใช้ `animateTransient`/`createPaperEffects`; ยกเลิกแล้วไม่เหลือ ghost/mask/timer; เสียงตรงจังหวะและไม่เล่นย้อนหลัง; reduced-motion ได้ผลลัพธ์ครบ; ผู้ใช้หยิบชิ้นต่อไปได้ระหว่างอนิเมชัน
6. **การเข้าถึง:** โฟกัสเห็นชัด คีย์บอร์ด/Esc ครบ `aria-label` บนปุ่มไอคอน เป้าแตะ ≥ ~40px
7. **ข้อความ:** ศัพท์ตรงกับของเดิม ปุ่มบอกการกระทำจริง error บอกสาเหตุและวิธีแก้ ไม่ขอโทษ
8. **Responsive:** ใช้งานได้ที่ 1600 / 1180 / 760 / 500 และจอเตี้ย (`max-height: 500px`)
9. **การวางไฟล์:** CSS ใหม่เป็นไฟล์ต่อท้ายใน `index.html` ไม่ใช้ `!important` โดยไม่มีเหตุผล

ถ้ายังไม่ได้ดูผลในเบราว์เซอร์จริง ให้บอกผู้ใช้ตรง ๆ ว่ายังไม่ได้ตรวจด้วยภาพ
