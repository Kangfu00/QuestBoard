description: เช็กลิสต์ตรวจงานดีไซน์ UI ของ Questboard ให้ตรงแนวเดียวกัน
---

ใช้ [แนวทางภาพ](../rules/design-system.md), [การออกแบบ UI บนโต๊ะกิลด์](../rules/ui-interaction.md) และ [กติกาการเคลื่อนไหว](../rules/motion-and-interaction.md) ตรวจส่วนที่แก้

1. **วัสดุ** ใช้ไม้ กระดาษ หนัง ทองเหลืองและหมึกของโปรเจกต์ ตรวจรูปที่ผู้ใช้อัปโหลดด้วยเส้นทางจริง
2. **สี** พื้นโต๊ะและเงาเป็นโทนอุ่น ใช้ค่าของระบบสีหนังสำหรับปกย้อมและโทนงาช้าง ตรวจพรีวิวเทียบกับปกจริง บัตรมานาใช้สีฟ้าเฉพาะบริบทของบัตร สีสถานะมีข้อความหรือรูปทรงประกอบ
3. **ตัวอักษร:** ข้อความไทยใช้ Noto (ไม่ใช่ Cinzel) line-height ≥ 1.6 ไม่เพิ่ม letter-spacing ให้ภาษาไทย ขนาดอ่านบนบอร์ด ≥ 11px
4. **เลย์เอาต์** ตรวจโต๊ะ รางบน ลิ้นชักขวา เคาน์เตอร์ซ้าย และแผงปิดเมื่อชั้นที่แก้ซ้อนกัน ใช้ขนาด A4 จากระบบเดิมและคงตำแหน่งที่ผู้ใช้จัดไว้
5. **การเคลื่อนไหว** ตรวจของติดมือ การบอกจุดวาง จังหวะปล่อยและยกเลิก คงสีและรูปทรงในสำเนาที่ใช้ลากหรือพับปิด เมื่อแผงไม้ปิดให้ตรวจทั้งการคลุมและการกดหรือ Tab เข้าลิ้นชักด้านหลัง เมื่อลากเปิดให้ตรวจว่าแสงจางตามระยะและเผยโหมดแสงปัจจุบัน
6. **การเข้าถึง:** โฟกัสเห็นชัด คีย์บอร์ด/Esc ครบ `aria-label` บนปุ่มไอคอน เป้าแตะ ≥ ~40px
7. **ข้อความ:** ศัพท์ตรงกับของเดิม ปุ่มบอกการกระทำจริง error บอกสาเหตุและวิธีแก้ ไม่ขอโทษ
8. **Responsive** ตรวจจอกว้าง จอมือถือ และจอเตี้ยเมื่อเลย์เอาต์หรือการลากได้รับผลกระทบ
9. **การวางไฟล์** ตรวจลำดับ CSS และความจำเพาะจาก `index.html` อธิบายเหตุผลถ้าใช้ `!important`

เมื่อแก้การลาก เปิดอ่าน หรือซูม ให้ลองในเบราว์เซอร์ตามส่วนที่เปลี่ยน

- ลากของเอียงตอนซูมเข้าและออก รวมถึงหลังเลื่อนโต๊ะ ลองวางชิดขอบซ้ายและขวา และปล่อยลงช่องที่รับได้ ช่องที่รับไม่ได้ หรือกด Esc ระหว่างลาก ตรวจตำแหน่งสุดท้ายและภาพจำลองที่ต้องหายไป
- เปิดสองเอกสารพร้อมกัน ลากให้ซ้อน คลิกสลับว่าใบไหนอยู่ด้านหน้า พิมพ์ในช่องหรือกดพลิกหน้า แล้วปรับหน้าต่างให้แคบหรือเตี้ย ตรวจว่ายังเลือก ลาก และปิดได้
- ซูมโต๊ะแล้วคืนขนาด เปิดมุมมองอ่านแล้วปิด และปรับขนาดภาพถ้างานแตะส่วนนี้ เทียบตำแหน่งเดิมบนโต๊ะหลังเปลี่ยนมุมมอง รวมถึงลองทางเลือกคีย์บอร์ด สัมผัส หรือ reduced-motion ตามพฤติกรรมที่แก้

ถ้ายังไม่ได้ดูผลในเบราว์เซอร์จริง ให้บอกผู้ใช้ตรง ๆ ว่ายังไม่ได้ตรวจด้วยภาพ
