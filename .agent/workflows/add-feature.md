---
description: ขั้นตอนเพิ่มฟีเจอร์ใหม่ให้ Questboard ตามธรรมเนียมของโปรเจกต์
---

1. เริ่มจาก [AGENTS.md](../../AGENTS.md) และ [กติกาโปรเจกต์](../rules/questboard.md) ตรวจ `git status --short` แล้วอ่าน handler, โมเดล และเทสต์ของฟีเจอร์ที่แตะ
2. ยืนยันขอบเขตจากคำขอ ระบุว่าจะแก้ UI พิกัด หรือข้อมูลถาวร งานที่แก้หลายส่วนใช้สเปกและแผนใน `docs/superpowers/` เมื่อช่วยอธิบายผลกระทบ
3. ใช้โมดูลและทางเข้าปกติของฟีเจอร์ ตรรกะที่ใช้ซ้ำหรือทดสอบแยกได้อยู่ในโมดูลฟีเจอร์ ส่วน `dist/app.mjs` เชื่อม state และ UI
4. ถ้าข้อมูลเปลี่ยน ให้ตรวจ `parseState`, การเขียน IndexedDB และไฟล์สำรองรุ่น 1 เพิ่มเทสต์ที่เปิดข้อมูลเดิมได้และบันทึกค่าใหม่ครบ
5. ถ้าเปลี่ยนภาพหรือการโต้ตอบ ให้ใช้ [แนวทางภาพ](../rules/design-system.md) และ [กติกาการเคลื่อนไหว](../rules/motion-and-interaction.md) ตรวจการยกเลิก คีย์บอร์ด และ reduced-motion ตามพฤติกรรมที่เปลี่ยน
6. เพิ่มเทสต์ที่ครอบคลุมพฤติกรรมใหม่หรืออาการถอยที่ชุดเดิมจับไม่ได้ เพิ่มโมดูล `dist/*.mjs` ใหม่ในสคริปต์ `check` และทำตาม [ขั้นตอนตรวจสอบ](verify.md)
7. ปรับ README เมื่อวิธีใช้งานเปลี่ยน อัปเดต backlog เมื่อแตะรายการเดิม และบันทึกหลักฐานที่จำเป็นต่อการตรวจย้อนหลัง
