# The Questboard — คู่มือการออกแบบ (Design System)

เอกสารนี้สรุปจากโค้ดจริงใน `dist/*.css` เพื่อให้ agent ทุกตัวออกแบบไปทางเดียวกัน
**หลักคิด:** นี่คือ "โต๊ะนายทะเบียนกิลด์" ของจริง — ไม้วอลนัต กระดาษเก่า หนัง เชือก ทองเหลือง และตราหมึก ไม่ใช่แดชบอร์ดหรือการ์ด SaaS
ความโดดเด่นทั้งหมดอยู่ที่ **ของบนโต๊ะ** (กระดาษ แฟ้ม ตรา ลิ้นชัก) ส่วนเมนู กล่องโต้ตอบ และข้อความรอบ ๆ ต้องเงียบ สุขุม และไม่แย่งความสนใจ

ถ้าสเปกหรือคำสั่งของผู้ใช้ขัดกับเอกสารนี้ ให้ทำตามผู้ใช้ แล้วแจ้งว่าต่างจากแนวเดิมตรงไหน

## 1. จานสี

พื้นหลักของโต๊ะและเงาใช้โทนน้ำตาลอุ่น กระดาษใช้สีครีม ปกหนังใช้ได้ทั้งสีย้อมหม่นและโทนอ่อนในระบบเลือกสี ส่วนบัตรนักผจญภัยใช้แสงมานาสีฟ้าเป็นจุดเด่นเฉพาะของบัตร

### หนังและสมุด
แฟ้ม สมุดงานประจำวัน และสมุดโน้ตใช้จานสีเดียวจาก `leather-colors.mjs` และวัสดุ `--leather-*` จาก `leather-folios.css` เลือกได้ทั้งสีสำเร็จรูป เช่น น้ำเงินหมึก ขาวงาช้างและขาวกระดูก หรือวงล้อสีแบบสี่ย้อมที่มีสี่ระดับความเข้ม ปกอ่อนใช้ตัวอักษรเข้มเพื่อให้อ่านได้

`cover-editor.mjs` ใช้ปกจริงทำตัวอย่างชื่อและสีขณะปรับ บนจอกว้างอยู่ข้างฟอร์มและบนจอแคบอยู่ด้านบน ค่าร่างมีผลต่อปกจริงเมื่อบันทึก ตรวจสีและคอนทราสต์เดียวกันบนโต๊ะ ในลิ้นชัก ขณะหยิบ และตอนเล่นภาพเปิดหรือปิดปก

**กฎ:** สีใหม่ที่ใช้ซ้ำ 2 ที่ขึ้นไป ให้ประกาศเป็น custom property ที่ `:root` หรือที่ scope ของคอมโพเนนต์ อย่า hardcode ซ้ำ

## 2. ตัวอักษร

| บทบาท | ฟอนต์ | ใช้กับ |
|---|---|---|
| `--serif` | Noto Serif Thai | หัวเรื่องเควส ชื่อกล่อง/แฟ้ม ข้อความยืนยัน ป้ายบนบอร์ด |
| `--body` | Noto Sans Thai | ข้อความทั่วไป ฟอร์ม ปุ่ม 14px / line-height 1.65 |
| `--display` | Cinzel | ตัวเลข XP ป้ายเล็กภาษาอังกฤษ ตรา (**ไม่มีอักษรไทย**) |

- ฟอนต์โหลดจาก Google Fonts ใน `index.html` เป็นการพึ่งพาภายนอกเดียวของโปรเจกต์ ห้ามเพิ่มฟอนต์/CDN ใหม่ และต้องมี fallback (`serif`/`sans-serif`)
- **ข้อความไทยห้ามใช้ Cinzel** และต้อง `line-height` ≥ 1.6 (สระ/วรรณยุกต์ซ้อนกัน) ไม่เพิ่ม `letter-spacing` บวกกับข้อความไทย
- `letter-spacing` กว้างและตัวพิมพ์ใหญ่เก็บไว้เฉพาะ Cinzel ที่เป็นป้ายตราและป้ายเล็กที่มีอยู่แล้ว อย่าขยายไปเป็นหัวข้อ eyebrow เหนือทุกหัวเรื่อง
- ขนาดที่ใช้อยู่: หัวเรื่องเควส 19px/600 (serif), หัวกล่อง 23px/500, รายละเอียดกระดาษ 11px, ป้ายเล็ก 8–10px ข้อความที่ผู้ใช้ต้องอ่านนานไม่ต่ำกว่า 11px
- ความยาวบรรทัดบนกระดาษถูกจำกัดด้วยความกว้างใบ (300 หน่วย / reader 380px) ข้อความยาวใช้ `-webkit-line-clamp` พร้อมดูเต็มในหน้าขยาย

## 3. เลย์เอาต์และโครงสร้าง

ใช้ [การออกแบบ UI บนโต๊ะกิลด์](ui-interaction.md) เมื่อต้องกำหนดจุดจับ การจัดวาง การเปิดเอกสารซ้อน หรือการซูม

- โต๊ะใช้พื้นที่หน้าจอเป็นหลัก รางเครื่องมืออยู่ด้านบน ลิ้นชักเก็บเควส แฟ้ม สมุดและรูปใช้ช่องร่วมด้านขวา เคาน์เตอร์ส่งเควสอยู่ด้านซ้าย และแผงไม้ปิดเต็มจอดึงขึ้นจากด้านล่าง
- รางบนและลิ้นชักขวาจองที่ผ่าน `--tool-space` และ `--storage-space` เคาน์เตอร์ซ้ายมีพฤติกรรมของตัวเองใน `quest-reception.css` และ `quest-reception.mjs` ตรวจพื้นที่ตกของแต่ละช่องตาม hit area จริง
- แผงปิดมีดาว ✧ กลางเนื้อไม้ มุมจอมืดและแสงอุ่นไหวตรงกลาง ระดับความทึบตามระยะลากจนเผยบรรยากาศของโต๊ะ แผงต้องอยู่เหนือทั้งโต๊ะและลิ้นชัก
- ใบเควส A4 ใช้ `--quest-paper-width` / `--quest-paper-aspect` เสมอ (ห้ามใส่ 300/350 ตรง ๆ ในโค้ดใหม่) ใบที่ถูกย่อ (แฟ้ม) ใช้ `--folio-paper-scale`
- ผู้ใช้ **จัดวางเอง** ตำแหน่ง มุมเอียง (`--rotation`) และลำดับชั้น (z) เป็นของผู้ใช้ ห้ามจัดเรียงอัตโนมัติทับโดยไม่ได้ขอ
- กล่องโต้ตอบใช้ `<dialog>` และรูปแบบหัว–เนื้อ–ท้ายเดิม งานที่ต้องมีตัวอย่างข้างฟอร์มใช้ `.cover-editor-dialog` ปุ่มหลักอยู่ขวาล่าง
- ตรวจลำดับชั้นจาก CSS และตัวจัดหน้าต่าง บรรยากาศบนโต๊ะอยู่เหนือของบนผิวโต๊ะ เอกสารที่เปิดขยายอยู่เหนือบรรยากาศ และแผงไม้คลุมพื้นที่ทำงานรวมทั้งลิ้นชัก
- จุดตัด responsive ที่ใช้: 1600, 1180, 1000, 760, 500 (กว้าง) และ `max-height: 500px` ต้องใช้งานได้ถึง ~380px

## 4. คอมโพเนนต์

- **ปุ่ม** `.button` สูงขั้นต่ำ 41px (small 31px) มุม 4px; `primary` = เขียวเสจ, `ghost` = โปร่งมีขอบ, `danger` = ดินแดง ปุ่มไอคอนล้วนต้องมี `aria-label`
- **ไอคอน** เป็น SVG เส้นบาง (stroke 1.25–1.5) ขนาด 12–20px สีตามบริบท ห้ามใช้ emoji เป็นไอคอน
- **ฟอร์ม** ช่องกรอกพื้นเข้มโปร่ง ขอบ `#a8b1842f` มุม 4px; โฟกัสขอบทอง
- **ป้ายบนบอร์ด** (`.board-label`) แถบไม้/หนังเล็ก พร้อมตะปู 2 จุด มี 3 สี: เริ่มต้น, sage, red
- **ตรา** (`.stamp`) วงกลม/สี่เหลี่ยม/ริบบิ้น ขอบ double หมึก `mix-blend-mode: multiply` เอียง −16° ตำแหน่งเป็นพิกัดในกระดาษ
- **Toast** แถบเสจอ่อนด้านล่าง มีปุ่มข้อความ (เช่น "เลิกทำ") ขีดเส้นใต้ ใช้ `role="status"`
- **ที่ว่าง (empty state)** บอกว่าทำอะไรต่อได้ ปุ่มเดียว น้ำเสียงแบบกิลด์ ไม่ใช้ภาพประกอบใหม่
- **กฎการเพิ่มของใหม่:** ใช้ภาษาวัสดุที่มีอยู่ก่อน (ไม้ กระดาษ หนัง ทองเหลือง หมึก เชือก) ถ้าต้องมีวัสดุใหม่ ให้อธิบายเหตุผลในสเปก และทำด้วย CSS/SVG

## 5. การเคลื่อนไหวและเสียง

> รายละเอียดของท่าทางทั้งหมด (หยิบ ลาก วาง เก็บ เปิด ปั๊มตรา) ดู **`.agent/rules/motion-and-interaction.md`** ซึ่งเป็นไฟล์หลักด้านอนิเมชัน ส่วนนี้เป็นเพียงสรุป

- เคลื่อนไหวเพื่อ **ตอบสนองการกระทำ** และแสดงว่าอะไรเปลี่ยน (เปิดแฟ้ม ปั๊มตรา เก็บกระดาษ) ไม่ใส่อนิเมชันตกแต่งที่ไม่มีใครกระตุ้น ยกเว้นบรรยากาศที่ปิดได้
- ใช้ระยะเวลาและ easing จาก `motion-tokens.mjs` / `motion-tokens.css` หรือค่าที่ฟีเจอร์นั้นใช้แล้ว อ่านกติกาการเคลื่อนไหวเมื่อต้องเพิ่มจังหวะ
- ของที่ถูกหยิบต้อง "มีน้ำหนัก": ยกขึ้น มีเงา เอียงตามแรงลาก แล้ววางลง **พิกัดที่ใต้เมาส์ห้ามหน่วง** มีแค่การหมุน/ย่อขยายที่ ease
- ต้องมี `@media (prefers-reduced-motion: reduce)` ทุกครั้ง (กฎรวมอยู่ท้าย `styles.css` แต่คอมโพเนนต์ที่ใช้ JS animation ต้องตรวจเอง)
- สำหรับการแก้ข้อมูล ให้บันทึกเจตนาของผู้ใช้ก่อนเล่นภาพยืนยัน ภาพเคลื่อนไหวที่ถูกขัดจังหวะต้องไม่บล็อกการบันทึก
- เสียงใช้ระบบใน `sound.mjs` / `sound-catalog.mjs` ตรงจังหวะสัมผัส ห้ามเสียงใหม่ที่ไม่มีที่มาและลิขสิทธิ์

## 6. การเข้าถึง (ขั้นต่ำที่ต้องมี)

- โฟกัสที่เห็นชัด: `outline: 2px solid #d7c58b; outline-offset: 5px` (ปุ่ม/ลิงก์) บนกระดาษใช้เส้นสีน้ำตาลเข้ม `#796236`
- ทุกการลากมีทางเลือกคีย์บอร์ด; Esc ยกเลิก; ปุ่มไอคอนมี `aria-label`
- ขนาดแตะเป้าหมายหลักไม่ต่ำกว่า ~40px (ยกเว้นตัวควบคุมรองที่มีอยู่แล้ว)
- คอนทราสต์ตัวอักษรบนกระดาษ (`#443923`/`#796c50` บน `#e9dab3`) และบนพื้นมืดต้องอ่านง่าย ถ้าจะใช้สีจางกว่านี้ให้ตรวจก่อน
- `lang="th"` และ `role="status"` สำหรับข้อความแจ้งเตือนต้องคงไว้

## 7. น้ำเสียงและข้อความ (ภาษาไทย)

- เป็นภาษาไทยสุภาพ กระชับ มีกลิ่นกิลด์พอประมาณ ไม่เล่นมุกจนอ่านยาก: เควส, กิลด์, ตรา, แฟ้ม, ลิ้นชัก, นายทะเบียน, ใบเควส
- **ศัพท์เดียวต่อสิ่งเดียว** ใช้คำเดิมทุกที่: กำลังทำ / สำเร็จ(แล้ว) / ไม่สำเร็จ / พักไว้ก่อน, เก็บเควส (ลิ้นชัก), แฟ้ม, เลิกทำ, สำรองลงไฟล์แล้ว
- ปุ่มบอกสิ่งที่จะเกิดจริง ("บันทึกเควส", "สร้างแฟ้มใหม่") ไม่ใช้ "ตกลง/Submit" และชื่อการกระทำต้องตรงกับข้อความ toast ที่ตามมา
- ข้อผิดพลาด: บอกว่าเกิดอะไรและแก้อย่างไร ไม่ขอโทษ ไม่คลุมเครือ (เช่น "บันทึกยาวได้ไม่เกิน 8000 ตัวอักษร")
- การลบ/เปลี่ยนที่ย้อนไม่ได้ต้องบอกผลกระทบก่อน และให้ "เลิกทำ" เมื่อทำได้
- อย่าใส่ข้อความอธิบายยาวบนบอร์ด ให้ UI อธิบายตัวเองด้วยวัสดุและการวางตำแหน่ง

## 8. สิ่งที่ห้าม (หลุดแนว)

- การ์ดมนสี่เหลี่ยมมุมเดียวกันหมด เงาเทาซ้ำ ๆ แบบ SaaS; พื้นไล่สีม่วง/น้ำเงิน; neumorphism; glassmorphism เกินแถบพรางหลัง dialog
- สีขาวบริสุทธิ์/ดำบริสุทธิ์ สีนีออน สีสดจัดนอกจากสีตรา/สถานะที่กำหนดไว้
- ใช้ SVG หรือสัญลักษณ์ที่โปรเจกต์ใช้แล้วสำหรับตัวควบคุม รองรับภาพที่ผู้ใช้อัปโหลดผ่านเครื่องมือรูปของโปรเจกต์
- หมุดบนกระดาษ (ถูกถอดออกแล้วใน "โต๊ะนายทะเบียนกิลด์")
- ป้ายตัวพิมพ์ใหญ่เว้นระยะกว้างเหนือทุกหัวข้อ, เลขลำดับ 01/02/03 ที่ไม่ใช่ลำดับจริง
- เอฟเฟกต์ fade-slide-up ตอนโหลดหรือ hover โดดเด่นกับทุกองค์ประกอบ
- ฟอนต์ใหม่, ไลบรารี UI, CSS framework, หรือรูปพื้นผิวภายนอก

## 9. วิธีเพิ่มสไตล์ให้ถูกที่

- ตรวจลำดับ `<link>` ใน `index.html` และความจำเพาะของ selector ใช้ class ของฟีเจอร์กับ CSS ที่เกี่ยวข้อง และอธิบายเหตุผลเมื่อจำเป็นต้องใช้ `!important`
- `styles.css` ยังมีสไตล์เลย์เอาต์เดิม (sidebar, topbar) ที่ถูกแทนด้วยโต๊ะเงียบ (`quiet-desk.css`) อย่านำกลับมาใช้โดยไม่จำเป็น
- ก่อนส่งงานดู workflow `ui-review`
