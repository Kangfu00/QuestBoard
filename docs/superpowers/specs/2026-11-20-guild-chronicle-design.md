# The Guild Chronicle (สมุดบันทึกประวัติศาสตร์การผจญภัย) — Design Specification

## 1. ปัญหาและเป้าหมาย (Problem & Goals)
- **ปัญหาเดิม:** เมื่อเควสถูกส่งมอบที่เคาน์เตอร์ส่งงาน (`questReception`) เควสจะถูกตั้งค่า `status: 'done'` และ `archived: true` แล้วถูกส่งไปกองรวมอยู่ใน **"ลิ้นชักเก็บของด้านขวา (#quest-drawer)"** ร่วมกับแฟ้ม รูปถ่าย และสมุดเล่มอื่น ๆ
- เมื่อทำเควสต่อเนื่องเป็นเวลาหลายสัปดาห์หรือหลายเดือน เควสสำเร็จจะสะสมเป็นสิบหรือหลายร้อยใบ ทำให้:
  1. ลิ้นชักขวารกและแออัด (Cluttered workspace) ค้นหาแฟ้มหรือของที่กำลังใช้อยู่ได้ยาก
  2. สิ้นเปลืองหน่วยความจำ DOM และทำให้การเลื่อนระนาบ 2D ของลิ้นชักหน่วง (Heavy performance overhead)
  3. เควสที่สำเร็จถูกทิ้งเกะกะ ขาดความรู้สึกภาคภูมิใจในความก้าวหน้า (Lack of sense of achievement)
- **เป้าหมาย:**
  1. แยกเควสที่ทำสำเร็จแล้ว (Completed / Turned-in Quests) ออกจากลิ้นชักขวาอย่างเด็ดขาด (`turnedIn: true` ไม่แสดงใน `trayItems`)
  2. รวมเควสสำเร็จทั้งหมดเข้าสู่ **"The Guild Chronicle (สมุดบันทึกประวัติศาสตร์การผจญภัย)"** เพียงเล่มเดียว
  3. แสดงผลแบบสมุดคู่ 2 หน้า (Two-page open spread):
     - **หน้าซ้าย (Chronicle Ledger / Index):** สารบัญทะเบียนเควสสำเร็จ น้ำหนักเบา ค้นหาและกรองได้ มีสรุปสถิติเควสและ XP รวม
     - **หน้าขวา (Showcase):** แสดงใบเควส A4 ตัวจริงฉบับประทับตราทอง "GUILD ACCEPTED" พร้อมรูปถ่าย โน้ต และแท็กต่าง ๆ
  4. ให้สิทธิ์ผู้ใช้เปิดดูได้จาก:
     - สถิติเควสบนหลังบัตรนักผจญภัย (`adventurer-back-done`)
     - ปุ่มทองเหลืองบนเคาน์เตอร์ส่งเควสฝั่งซ้าย (`reception-drawer`)
  5. รองรับการกู้คืนเควสกลับมาทำใหม่ (Reopen Quest) หากต้องการนำเควสกลับคืนสู่บอร์ดทำงาน

## 2. โมเดลข้อมูลและการแยกพื้นที่จัดเก็บ (Data Architecture)
- **รูปแบบข้อมูล:** คง `version: 1` ไม่มีการเพิ่มเลขเวอร์ชัน
- **ฟิลด์ของเควสที่ส่งมอบ:**
  - `status: 'done'`
  - `archived: true`
  - `turnedIn: true` (ค่าดั้งเดิมถ้าไม่มีให้ถือเป็น `false` หรือ fallback ตาม `status === 'done' && archived'`)
  - `turnedInAt: string (ISO 8601)` บันทึกเวลาที่ส่งมอบจริง
- **การแยกพื้นที่ใน `storage-tray.mjs`:**
  - กรองเฉพาะไอเทมที่ `!item.turnedIn`:
    ```javascript
    export function trayItems(state, search = '') {
      const term = search.trim().toLocaleLowerCase();
      return state.items.filter(item =>
        item.archived && !item.turnedIn &&
        (item.type === 'folder' || item.type === 'photo' || item.type === 'notebook' || (item.type === 'quest' && !item.folderId))
      )...
    }
    ```
  - ลิ้นชักขวาจะไม่ถูกเควสสำเร็จไหลเข้ามาสุมอีกต่อไป

## 3. หน้าตาและการจัดวาง (Visual Design & Spatial Layout)
- **สไตล์ศิลป์:**
  - สมุดปกหนังหนาสีน้ำตาลเข้มเกือบดำ (`#2b180d` / `#1c0e07`) เดินขอบทองเหลืองโบราณ ประทับตรากิลด์สีทองนูนต่ำ
  - หน้ากระดาษพาร์ชเมนต์คู่ (Spread Width: ~880px – 920px, Height: min(640px, 86vh))
- **หน้าซ้าย: ทะเบียนสารบัญ (Chronicle Index):**
  - หัวกระดาษ: ชื่อสมุด "GUILD CHRONICLE · บันทึกเกียรติยศนักผจญภัย"
  - สรุปสถิติ: จำนวนเควสสำเร็จทั้งหมด และ XP รวมสะสม
  - แถบค้นหาและฟิลเตอร์ (Search input, Category tabs, Rank filters)
  - รายการเควส (Scrollable Chronicle Ledger):
    - แถวละ 1 เควส พร้อมตรา `[ACCEPTED]`, ชื่อเควส, วันที่ส่งมอบ, ริบบิ้นแรงก์ (`A/B/C`), และ XP
    - แถวที่เลือกอยู่จะมีกรอบทองเรืองแสง
- **หน้าขวา: หน้าจัดแสดงใบเควสตัวจริง (Quest Showcase):**
  - แสดงใบเควส A4 ตัวจริง (300px × 424px) ด้วยฟังก์ชัน `renderQuest(quest)`
  - ประทับตราทอง **GUILD ACCEPTED** ขนาดใหญ่เฉียงอยู่กลางใบเควส
  - ปุ่มแถบการจัดการด้านล่าง:
    - `[↩ นำเควสกลับมาทำใหม่]`: กู้คืนเควสกลับสู่บอร์ดทำงาน
    - `[🔄 พลิกดูโน้ตด้านหลัง]`: ดูโน้ตและเควสย่อย

## 4. อนิเมชั่นและการเคลื่อนไหว (Motion Governance)
- **การเปิดสมุด:** คลี่กางออกจากกึ่งกลางด้วย `transform: scale(0.96) -> scale(1)` + `opacity: 0 -> 1` (Duration 280ms, cubic-bezier(.2, .8, .3, 1)) พร้อมเสียง `folderOpen`
- **การเปลี่ยนเควสที่เลือก:** ใบเควสหน้าขวาเปลี่ยนด้วย crossfade + slide 4px เล็กน้อย (Duration 180ms) พร้อมเสียง `paperSlide`
- **การปิดสมุด:** ยุบกลับสู่กึ่งกลางพร้อมเสียง `drawerClose`
- **Reduced Motion:** เมื่อเปิด `prefers-reduced-motion: reduce` ให้ตัดการหมุนและขยายทั้งหมด ใช้ instant opacity crossfade (100ms)

## 5. การทดสอบและการตรวจสอบ (Verification Strategy)
- สร้าง `tests/guild-chronicle.test.mjs` ทดสอบ:
  1. การคำนวณสถิติและตัวกรองเควสสำเร็จ (ค้นหา, หมวดหมู่, แรงก์)
  2. การเรนเดอร์หน้าต่างสมุดและการสลับเควสที่เลือก
  3. การกู้คืนเควสกลับสู่บอร์ด (`reopenQuest`)
  4. การแยกออกจาก `trayItems` ของลิ้นชักขวาอย่างสมบูรณ์
- ผ่าน `npm run check`
- ผ่าน `npm test` ทั้งชุดรวม 100%
