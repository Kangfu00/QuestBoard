# The Questboard — กระดานนักผจญภัย

กระดาน To-do ธีมกิลด์แฟนตาซี สร้างด้วย HTML/CSS/JavaScript โดยไม่ต้องติดตั้ง dependencies

## เปิดในเครื่อง

ต้องมี Node.js 20 ขึ้นไป

```sh
npm run dev
```

เปิด http://127.0.0.1:4173 หรือดับเบิลคลิก `Start-Questboard.cmd` เพื่อเปิดเซิร์ฟเวอร์แบบซ่อนหน้าต่างแล้วเปิดบอร์ดในเบราว์เซอร์เริ่มต้น

## สำรองไฟล์อัตโนมัติและเปิดพร้อม Windows

- เซิร์ฟเวอร์สำรองข้อมูลทุกครั้งที่มีการแก้ไขไปที่ `D:\Pro_J\บอร์ด\Questboard-Backups\latest.json` โดยเก็บฉบับก่อนหน้า 30 รุ่นใน `history` ไฟล์ทั้งหมดนำเข้าด้วยเมนูสำรองข้อมูลได้
- **หลังอัปเดตครั้งแรก ให้รีเฟรชหน้าบอร์ดเดิมในเบราว์เซอร์ที่มีเควสอยู่ แล้วรอ “สำรองลงไฟล์แล้ว”** ก่อนล้างข้อมูลเบราว์เซอร์ เควสเดิมจึงจะถูกส่งลงไฟล์ครั้งแรก
- เมื่อล้างข้อมูลเว็บไซต์แล้วเปิดบอร์ดใหม่ ระบบอ่านไฟล์สำรองกลับมาอัตโนมัติ รวมรูป ตรา แฟ้ม และตำแหน่งกระดาษ หากพบข้อมูลสองฉบับที่แก้ไขต่างกัน จะให้เลือกและดาวน์โหลดฉบับเบราว์เซอร์เก็บไว้ก่อน
- ดูสถานะ เวลา และโฟลเดอร์สำรองที่ **เครื่องมืออื่น ๆ → ตกแต่ง / สำรองข้อมูล** ข้อความ “รอสำรองไฟล์” หมายถึงยังมีเฉพาะฉบับในเบราว์เซอร์ ระบบลองใหม่ทุก 15 วินาที
- ติดตั้งเปิดพร้อม Windows ด้วย `powershell.exe -NoProfile -File .\Install-Questboard-Autostart.ps1` เปิดหลังเข้าสู่บัญชีผู้ใช้ โดยไม่ต้องใช้สิทธิ์ผู้ดูแล
- ยกเลิกเปิดพร้อม Windows ด้วย `powershell.exe -NoProfile -File .\Disable-Questboard-Autostart.ps1`
- หากย้ายโฟลเดอร์โปรเจกต์ ให้ติดตั้งการเปิดพร้อม Windows ใหม่ และย้ายโฟลเดอร์ `Questboard-Backups` ไปไว้ข้างโฟลเดอร์ `guild-board` เช่นเดิม
- ไฟล์สำรองอยู่บนเครื่องเดียวกัน การล้างข้อมูลเบราว์เซอร์จะไม่ลบไฟล์เหล่านี้ แต่ควรคัดลอกโฟลเดอร์สำรองไปอีกไดรฟ์เป็นระยะหากต้องการป้องกันไดรฟ์เสีย

## การใช้งาน

- หน้าหลักเป็นบอร์ดเต็มจอ เหลือเพียงกระดาษ ป้าย แฟ้ม และหูจับลิ้นชักสามอันที่มุมขวา: **เครื่องมือ / เก็บเควส / แฟ้ม**
- เปิดลิ้นชัก **เครื่องมือ** แล้วคลิกปากกาเพื่อสร้างเควส คลิกชื่อบนกระดาษเพื่อแก้ไข
- หยิบตรา **สำเร็จ / ไม่สำเร็จ / พักไว้ก่อน** ตราจะตามเมาส์ คลิกซ้ายที่กระดาษเพื่อปั๊มต่อได้หลายใบ คลิกขวาหรือ Esc เพื่อเก็บตราคืน
- จุดกึ่งกลางตราอยู่ตรงที่คลิกบนกระดาษ แม้ซูมหรือเอียงกระดาษ หมึกที่ล้ำขอบจะถูกตัดตามขอบกระดาษ ตำแหน่งถูกบันทึกและสำรองลงไฟล์ด้วย การปั๊มด้วยคีย์บอร์ดคงตำแหน่งเดิม
- ใช้คีย์บอร์ดหยิบตราได้ด้วย Enter แล้ว Tab ไปยังกระดาษและกด Enter/Space เพื่อปั๊ม
- ปั๊มได้บนด้านหน้าเอกสารที่เปิดขยายและใบเควสฝั่งขวาของแฟ้มด้วย รวมเควสที่เก็บอยู่ในแฟ้ม ตำแหน่งหมึกตรงจุดคลิกและแสดงร่วมกันทุกมุมมอง เควสยังอยู่ในที่เก็บเดิม โน้ตด้านหลังกับช่องพิมพ์ยังใช้งานได้ คลิกขวาหรือ Esc เพื่อเก็บตราคืน
- เมนูรูปแบบตรา ตราที่อัปโหลด ค้นหา ป้าย ซูม และการตั้งค่าอยู่ใน **เครื่องมืออื่น ๆ** ภายในลิ้นชัก กด `/` เพื่อเปิดค้นหาได้ทันที
- เพิ่มและแก้ไขเควส: ชื่อ รายละเอียด หมวดหมู่ ความสำคัญ กำหนดเสร็จ และ XP
- เพิ่มภาพประกอบหนึ่งภาพต่อเควส: PNG, JPG, WebP สูงสุด 5 MB ระบบย่อด้านยาวเหลือไม่เกิน 960 px ก่อนบันทึก
- วางรูปเป็นใบแยกโดยลากไฟล์ลงบนโต๊ะ หรือกด **วางรูปบนโต๊ะ** ข้างปุ่ม **เขียนเควสใหม่** ในรางเครื่องมือด้านบน รองรับ PNG, JPG และ WebP สูงสุด 5 MB คลิกมุมล่างเพื่อเขียนโน้ตด้านหลัง เปิดรูปแล้วสลับโทนทองกับสีต้นฉบับได้ ลากเก็บและนำกลับจากลิ้นชักขวาได้พร้อมรูปและโน้ต
- ชี้รูปแล้วลากมือจับ ↘ ข้างมุมล่างเพื่อปรับขนาดโดยคงสัดส่วนเดิม ใช้ Tab ไปที่มือจับแล้วกดลูกศรได้ ขนาดที่ตั้งไว้จะตามรูปไปในลิ้นชักและอยู่ในไฟล์สำรอง
- ลากที่หัวกระดาษหรือป้ายเพื่อย้าย หรือใช้ Tab และปุ่มลูกศร (Shift ย้ายครั้งละ 25 px)
- ลากที่ทับกระดาษทองเหลืองวางบนใบเควสเพื่อยึดมุมที่ใกล้ที่สุด ลากออกเพื่อปล่อยใบเควส คลิกตุ้มเพื่อเลือกตราหรืออัปโหลดรูปของตัวเอง ตำแหน่งและรูปตรารวมอยู่ในไฟล์สำรอง
- กระดาษยกตัวพร้อมเงาและเอียงเล็กน้อยตามแรงลาก จุดที่หยิบยังติดเมาส์แม้ซูมบอร์ด และกระดาษแนบลงเมื่อปล่อย
- วางกระดาษได้เต็มพื้นที่บอร์ดที่มองเห็น ขอบเขตรองรับกระดาษเอียง และตำแหน่งยังอยู่เดิมเมื่อรีเฟรชหรือเปลี่ยนขนาดหน้าต่าง
- ประทับตรา สำเร็จ / ไม่สำเร็จ / พักไว้ก่อน เลือกตรากิลด์ ตราหมึก หรือริบบิ้น
- แอนิเมชันด้ามตราไม้กดลง รอยหมึกกระจาย และกระดาษขยับตามแรงกด รองรับการตั้งค่าลดการเคลื่อนไหวของระบบ
- ลิ้นชักซ่อนที่มุมขวา: ดึงหูจับไปทางซ้ายหรือคลิกเพื่อเปิด ดึงกลับ/กดปิดเพื่อซ่อน
- ลากหัวกระดาษเควสมาปล่อยในช่องรับของลิ้นชักเพื่อเก็บ สถานะ รูป และ XP ยังคงอยู่
- กระดาษจะเลื่อนเข้าช่องใต้ขอบไม้ของลิ้นชักทีละส่วน เมื่อสร้างเควสใหม่ กระดาษจะออกจากด้านลิ้นชักเครื่องมือมาคลี่ในพื้นที่บอร์ดที่กำลังมองอยู่ หยิบต่อได้ระหว่างคลี่
- ขณะลากกระดาษ ช่องรับในลิ้นชักจะพร้อมใช้งานทันที เพื่อให้ปล่อยเข้าเก็บได้แม้ลากเร็ว
- ค้นหาเควสที่เก็บไว้ในลิ้นชัก คลิกเปิดดู/แก้ไข หรือกดลูกศรเพื่อนำกลับตำแหน่งเดิม
- เปิดลิ้นชัก **แฟ้ม** แล้วกด **สร้างแฟ้มใหม่** เพื่อสร้างแฟ้มและเลือกสี มีช่องค้นหาแยกสำหรับชื่อแฟ้มหรือเควสด้านใน
- ลากเควสลงบนแฟ้มในลิ้นชักหรือบนบอร์ดเพื่อจัดเก็บ ระหว่างลากสามารถเลื่อนไปที่หูจับ **แฟ้ม** เพื่อเปิดลิ้นชัก แล้วปล่อยบนชื่อแฟ้มที่ต้องการ
- ลากหูจับแฟ้มออกมาวางบนบอร์ดได้ ลิ้นชักเก็บเควสแสดงเฉพาะกระดาษที่ยังไม่เข้าแฟ้ม
- คลิกแฟ้มเพื่อเปิดดูและค้นหาเควสด้านใน ลากที่หูจับหน้าเควสออกมาวางบนบอร์ด หรือย้ายเข้าแฟ้มอื่นได้
- แฟ้มเป็นหนังพับเย็บขอบ ผูกเชือกผ่านตาไก่ทองเหลือง พร้อมป้ายชื่อกระดาษ เลือกหนังน้ำตาล เขียวมอส หรือแดงไวน์ได้
- ตอนเปิด เชือกจะคลายก่อนปกหนังกางเป็นสองฝั่ง ซ้ายเป็นปกหนังกับสารบัญ ขวาเป็นใบเควสที่เลือกเต็มใบ ปิดแล้วกระดาษจะรวมเข้าที่ก่อนปกพับและเชือกรัดกลับ
- ปิดแฟ้มด้วยปุ่มปิดหรือ Esc จะเห็นปกพับกลับและเชือกผูก ขณะเล่นอนิเมชั่นยังคลิกบอร์ดต่อได้ เปิดแฟ้มซ้ำได้ทันที และรองรับการตั้งค่าลดการเคลื่อนไหวของระบบ
- ลากแฟ้มกลับช่องรับของลิ้นชัก **แฟ้ม** เพื่อเก็บทั้งแฟ้ม การลบแฟ้มจะย้ายเควสด้านในไปอยู่ในลิ้นชักเก็บเควส ไม่ลบเควส
- ใช้เสียงบันทึกจริง 46 ไฟล์สำหรับ 18 จังหวะ แยกกระดาษ ไม้ โลหะ หนัง เชือก และเสียงเขียน สลับตัวอย่างโดยไม่เลือกไฟล์เดิมติดกันในแต่ละจังหวะ พร้อมขยับระดับและความเร็วเล็กน้อย เริ่มทำงานหลังการคลิกครั้งแรก ปรับความดังหรือปิดเสียงได้ใน **เครื่องมืออื่น ๆ**
- ปรับระดับเสียงแยกตามไฟล์และน้ำหนักวัสดุ พร้อมควบคุมเสียงที่ซ้อนกัน ค่าเริ่มต้นสำหรับเบราว์เซอร์ใหม่เป็น 65% และยังเก็บค่าปิดเสียง/ความดังที่เคยตั้งไว้ เสียงปั๊มตรงจังหวะสัมผัสกระดาษและเสียงแฟ้มตามจังหวะเชือก/ปก หากยกเลิกอนิเมชั่นหรือไฟล์เสียงมาไม่ทัน ระบบจะไม่เล่นเสียงย้อนหลัง
- เพิ่มตราของตัวเองในคลังตรา: PNG, JPG, WebP ไม่เกิน 2 MB รูปจะถูกย่อเหลือด้านยาวไม่เกิน 512 px
- ค้นหา กรองสถานะ ซูม จัดเรียง และเลือกพื้นบอร์ดได้ 3 แบบ
- บันทึกอัตโนมัติทั้ง IndexedDB และไฟล์ผ่านเซิร์ฟเวอร์ในเครื่อง ข้อมูลไม่ซิงก์ข้ามเครื่อง
- ส่งออก/นำเข้า JSON ในเมนูจัดแต่งกระดาน สำหรับสำรองหรือย้ายเครื่อง
- รองรับสูงสุด 500 รายการรวมเควส/ป้าย/แฟ้ม และ 30 ตราที่อัปโหลด
- ไฟล์สำรองรวมรูปทั้งหมดสูงสุด 90 MB หากเต็ม ระบบปฏิเสธรูปหรือรายการใหม่ก่อนเปลี่ยนข้อมูลเดิม

## ตรวจสอบ

```sh
npm test
npm run check
```

คำสั่งทดสอบเรียงไฟล์ทีละชุด เพื่อไม่ให้เบราว์เซอร์ทดสอบหลายโปรไฟล์แย่งเวลาวาดอนิเมชั่นกัน

ชุดทดสอบรูปมีเบราว์เซอร์จำลองแยกข้อมูล ใช้ Edge/Chrome ที่ติดตั้งไว้บน Windows เพื่อตรวจ DOM โฟกัสและการจัดรูปทั้ง 4 พื้นที่ โดยไม่เปิดข้อมูลเควสจริง ถ้าไม่มี Chromium จะข้ามเฉพาะข้อนี้ หรือกำหนด `PHOTO_TEST_BROWSER` เป็นพาธโปรแกรมที่ติดตั้งไว้ได้ การลากในเทสต์นี้ใช้ pointer event จำลอง

ชุดทดสอบแสงใช้เบราว์เซอร์แยกข้อมูลเช่นกัน ตรวจ CSS animation จริง การซ้อนชั้น การกดผ่านบรรยากาศ และโหมดลดการเคลื่อนไหว กำหนด `ATMOSPHERE_TEST_BROWSER` เพื่อเลือก Chromium ที่ติดตั้งไว้ หรือ `ATMOSPHERE_TEST_SCREENSHOTS` เป็นโฟลเดอร์สำหรับบันทึกภาพเช้า/เย็นของฉากทดสอบ

ชุดทดสอบเสียงตามเวลาใช้โปรไฟล์ Chromium ใหม่และข้อมูลสมมติ ตรวจการคลิกเริ่มแบบ trusted การถอดรหัส WAV จริง สัญญาณในกราฟเสียง การเปลี่ยนผ่านและการหยุดเสียง โดยปิดเสียงออกลำโพง ไม่เปิดหน้าบอร์ดหรือข้อมูลจริง กำหนด `DAYPART_TEST_BROWSER` เพื่อเลือก Chromium ที่ติดตั้งไว้ได้ การเปลี่ยนนาฬิกา การตั้งค่าและการซ่อนหน้าในฉากนี้เป็นเหตุการณ์จำลอง

ชุดทดสอบเงื่อนไขใช้โมเดล ตัวเลือก และอนิเมชั่นจริงบนข้อมูลสมมติ รวมทั้งการสำรองลงโฟลเดอร์ชั่วคราว กำหนด `PREREQUISITE_TEST_BROWSER` เพื่อเลือก Chromium หรือ `PREREQUISITE_TEST_SCREENSHOTS` เพื่อเก็บภาพฉากทดสอบ

`dist/` เป็นไฟล์เว็บที่ deploy ได้ทันที ไม่ต้อง build

## ลิ้นชักเก็บของด้านขวา

ลิ้นชักเควสและแฟ้มรวมเป็นถาดไม้ใบเดียวที่ขอบขวา ดึงหูจับไปทางซ้ายหรือคลิกเพื่อเปิด ถาดแบ่งพื้นที่หน้าจอกับบอร์ด จึงเห็นทั้งสองฝั่งพร้อมกัน บอร์ดคงขนาดกระดาษเดิมและเลื่อนดูพื้นที่ส่วนที่เหลือได้ ปิดถาดแล้วบอร์ดขยายกลับ เหลือเฉพาะหูจับที่ขอบจอ

ลากกระดาษหรือแฟ้มจากบอร์ดเข้าไปวางตำแหน่งที่ต้องการในถาดได้ หรือลากไปใกล้หูจับด้านขวาเพื่อให้เปิดระหว่างถือของ การลากจัดตำแหน่งบนบอร์ดตามปกติจะไม่เปิดถาดมาบังโต๊ะ

ลากหัวกระดาษหรือสันแฟ้มเพื่อจัดตำแหน่งในถาด ลากออกไปปล่อยบนบอร์ดเพื่อนำกลับ ค้นหาเควส ชื่อแฟ้ม และเควสด้านในจากช่องค้นหาเดียว สร้างแฟ้มใหม่ได้จากปุ่มภายในถาด คลิกปกแฟ้มเพื่อเปิดอ่านโดยยังเก็บแฟ้มไว้ในลิ้นชัก เควสในแฟ้มยังอยู่ครบ

ตำแหน่งในถาดบันทึกแยกจากตำแหน่งบนบอร์ดและสำรองลงไฟล์ด้วย รองรับปุ่มลูกศรที่หัวกระดาษ/สันแฟ้มเพื่อจัดตำแหน่ง และ Enter เพื่อเปิดอ่าน เครื่องมืออยู่ในรางไม้ด้านบน เปิดพร้อมถาดเก็บของด้านขวาได้


## รางเครื่องมือด้านบน

ดึงหูจับเครื่องเขียนลงมาหรือคลิกเพื่อเปิดรางเตี้ยด้านบน ภายในมีปากกาและตราปั๊มสามสถานะเรียงแนวนอน เมื่อเปิด บอร์ดจะเลื่อนลงเพื่อกันพื้นที่ให้ราง โดยขนาดกระดาษคงเดิม เปิดรางเครื่องมือและถาดเก็บของด้านขวาพร้อมกันได้

คลิกปากกาเพื่อสร้างเควส หรือหยิบตราไปปั๊มตามเดิม รางจะพับกลับเมื่อหยิบเครื่องมือ เมนู **เครื่องมืออื่น ๆ** เปิดเป็นหน้าต่างแยกสำหรับค้นหา กรอง เลือกตรา ปรับเสียง สำรองข้อมูล และตั้งค่า กด `/` เพื่อเปิดค้นหา และ Esc เพื่อปิดหน้าต่างเมนู


## พลิกด้านหลังกระดาษ

กดมุมพับขวาล่างของใบเควสบนบอร์ดหรือในถาด เพื่อยกกระดาษขึ้นมาแล้วพลิกไปด้านหลัง ด้านหน้ายังคงเป็นใบประกาศเดิม ด้านหลังมีโน้ตและรายการเควสย่อย เพิ่ม แก้ชื่อ ติ๊กสำเร็จ หรือลบแต่ละข้อได้ โดยไม่เปลี่ยนสถานะเควสหลัก เควสในแฟ้มเปิดด้านหลังได้จากมุมกระดาษที่เลือกหรือปุ่มพลิกจดบันทึกใต้ใบเควส

โน้ตบันทึกอัตโนมัติระหว่างพิมพ์และก่อนปิดหน้าต่าง รองรับสูงสุด 8,000 ตัวอักษร และเควสย่อย 80 ข้อ ข้อละ 240 ตัวอักษร ข้อมูลรวมในไฟล์สำรองเดิมด้วย กดกลับด้านหน้าเพื่ออ่านใบเควส หรือกดแก้ไขใบเควสเพื่อเปิดแบบฟอร์มเดิม ปิดด้วย × หรือ Esc เพื่อกลับตำแหน่งเดิม

การพลิกใช้ชั้นกระดาษโค้งที่เคลื่อนตามกัน พร้อมเงาเคลื่อน รูหมุดตรงกันทั้งสองด้าน และเสียงกระดาษ รองรับการลดการเคลื่อนไหวของระบบ หากบันทึกไม่สำเร็จ ร่างจะยังอยู่ในหน้าต่างพร้อมปุ่มลองบันทึกใหม่


## แฟ้มหนังกางสองฝั่ง

คลิกแฟ้มเพื่อคลายเชือกและเปิดปกหนัง ด้านซ้ายมีป้ายชื่อแฟ้ม ช่องค้นหา สารบัญ และกระเป๋าหนังสำหรับรับเควส ด้านขวาแสดงใบเควสที่เลือกเต็มใบพร้อมขอบกระดาษซ้อน เลือกชื่อจากสารบัญเพื่อเปลี่ยนใบที่ดู ใช้ปุ่มลูกศรขึ้น/ลงหรือ Home/End ในสารบัญได้

ลากหัวกระดาษด้านขวาหรือหูจับข้างชื่อในสารบัญออกไปวางบนบอร์ด/ถาด หรือย้ายเข้าแฟ้มอื่นได้ กดมุมกระดาษเพื่อพลิกจดโน้ต เควสย่อย หรือใช้ปุ่มแก้ไข/นำกลับบอร์ดใต้กระดาษ การเลือกและค้นหาไม่เปลี่ยนสถานะ ตำแหน่ง หรือแฟ้มของเควส

ปิดด้วย × หรือ Esc: ปึกกระดาษจะรวมให้ตรง ปกพับกลับ และเชือกรัด ขณะเล่นอนิเมชั่นยังใช้บอร์ดต่อได้ เปิดซ้ำได้ทันที ระบบลดการเคลื่อนไหวจะแสดงปลายทางโดยตรง

## โต๊ะนายทะเบียนกิลด์ (16 พฤศจิกายน 2026)

พื้นที่หลักเป็นโต๊ะไม้สำหรับวางใบเควส ไม่มีหมุดหรือรูหมุดบนกระดาษทั้งสองด้าน กระดาษที่หยิบจะยกและเอียงตามจุดจับ ส่วนแฟ้มหนังยังคงแข็ง ลิ้นชักด้านขวาขยับของตามแรงดึงเล็กน้อยแล้วคืนตัว โดยไม่เปลี่ยนพิกัดที่จัดไว้

แฟ้มเปิดแสดงขอบกระดาษตามจำนวนเควสจริง สูงสุดสี่ชั้นตกแต่ง เควสเดียวจะไม่มีชั้นกระดาษปลอม และริบบิ้นที่สารบัญช่วยจำใบที่เลือกไว้ระหว่างการใช้งานครั้งนี้ แม้สลับแฟ้มหรือค้นหาชั่วคราว เสียงวางและเก็บกระดาษสัมพันธ์กับจังหวะสัมผัส รองรับการหยิบซ้ำและลดการเคลื่อนไหว

หลังอัปเดตให้กด Ctrl+F5 หนึ่งครั้ง ข้อมูลเควสและรูปแบบไฟล์สำรองใช้ระบบเดิม

## หน้าต่างเอกสารหลายใบ (16 พฤศจิกายน 2026)

กดชื่อเควสเพื่อเปิดด้านหน้า กดมุมกระดาษเพื่อเปิดด้านหลัง และกดแฟ้มเพื่อเปิดสารบัญ เปิดเควสและแฟ้มหลายอันพร้อมกันได้ ลากบนกระดาษเควสหรือหัวแฟ้มเพื่อย้าย คลิกหรือโฟกัสเอกสารเพื่อยกขึ้นด้านหน้า กด Esc ปิดเฉพาะใบหน้า โดย Esc ยังยกเลิกการลาก/เก็บตราที่ถืออยู่ก่อน

กดเอกสารเดิมซ้ำจะยกใบที่เปิดอยู่โดยไม่สร้างโน้ตซ้ำ แต่ละแฟ้มจำการค้นหา การเลือกและตำแหน่งของตัวเองในรอบใช้งานนี้ ลากกระดาษออกจากแฟ้มได้ขณะแฟ้มอื่นยังเปิดอยู่ หัวหน้าต่างใช้ปุ่มลูกศรย้ายได้ และ Shift ย้ายทีละพิกเซล ตำแหน่ง UI แยกจากพิกัดเควสบนโต๊ะ/ในลิ้นชัก

ไอเดียเพิ่มเติมที่ขอพักไว้บันทึกใน docs/ideas-backlog.md

ตัวอ่านใบเควสไม่มีแถบควบคุมแยกเหนือ/ใต้กระดาษแล้ว ปุ่มแก้ไขและปิดอยู่บนแผ่น และมุมพับขวาล่างใช้พลิกกลับไปมาได้ทั้งสองด้าน ช่องโน้ต เควสย่อยและปุ่มต่าง ๆ ยังคงกด/พิมพ์โดยไม่ลากหน้าต่าง

ใบเควสใช้สัดส่วน A4 (210:297) กว้าง 300 หน่วย สูงประมาณ 424.29 หน่วย ทั้งบนโต๊ะ ลิ้นชัก หน้าขยาย และในแฟ้ม หัวเรื่องกับรายละเอียดอยู่เหนือช่องรับตรา ส่วนใบที่มีรูปวางรูปแบบรักษาสัดส่วนคู่กับข้อความ รูปและข้อความไม่เปลี่ยนตำแหน่งหลังปั๊มตรา แถบข้อมูลกับกำหนดส่งอยู่ด้านล่าง หน้าขยายและกระดาษในแฟ้มย่อพอดีทั้งความกว้างและความสูง ด้านหลังแบ่งพื้นที่โน้ตกับเควสย่อยที่เลื่อนได้ ตราเดิมแสดงในตำแหน่งตามสัดส่วนของใบใหม่ และไฟล์สำรองเดิมยังเปิดได้ หลังอัปเดตกด Ctrl+F5

กรอบรูปบนใบเควสหุ้มตามสัดส่วนภาพจริง: แนวตั้งเป็นกรอบสูง แนวนอนเป็นกรอบกว้าง และรูปจัตุรัสคงสัดส่วนเดิมภายในขอบกระดาษ รูปย่อให้พอดีพื้นที่โดยไม่บีบหรือครอปเนื้อภาพ ใช้กับรูปที่ใส่ไว้แล้วด้วย

รูปแนวตั้ง/จัตุรัสจัดข้างข้อความ ส่วนรูปแนวนอนจัดใต้ข้อความโดยอัตโนมัติ ชี้หรือโฟกัสรูปแล้วกด **จัดรูป** เพื่อลากตำแหน่ง ลากปุ่ม **↘** เพื่อปรับขนาดรักษาสัดส่วน และ **↻** เพื่อเอียงรูปเล็กน้อย ปุ่มเหล่านี้ใช้ลูกศรบนคีย์บอร์ดได้ด้วย กด **เสร็จ** เพื่อจำแยกตามเควส หรือ **ยกเลิก / Esc** เพื่อทิ้งการลองจัด กด **อัตโนมัติ** แล้ว **เสร็จ** เพื่อคืนการจัดตามแนวรูป

ดับเบิลคลิกรูปหรือกด **ขยาย** เพื่อดูภาพเต็มพร้อมอนิเมชั่นยกออกจากกระดาษ ปิดด้วย **× / Esc / คลิกนอกภาพ** เพื่อวางกลับ รูปและตำแหน่งที่จัดไว้รวมอยู่ในไฟล์สำรองตามระบบเดิม หลังอัปเดตกด Ctrl+F5

## เควสที่ต้องสำเร็จก่อน

เปิดสร้างหรือแก้ไขเควส แล้วดูช่อง **ต้องสำเร็จก่อน** ค้นหาและเลือกเควสได้หลายใบ รวมใบที่เก็บในแฟ้ม/ลิ้นชัก ต้องสำเร็จครบทุกใบจึงปลดล็อก ระบบกันการเลือกตัวเองหรือเควสที่ทำให้รอกันเป็นวง

ใบที่รอมีสัญลักษณ์กุญแจ **รอ N เควส** ชี้เพื่อดูชื่อเควสที่ต้องสำเร็จก่อน อ่าน จัดรูป จดโน้ต ลากและเก็บได้ตามปกติ แต่ยังปั๊มตราสำเร็จไม่ได้ เมื่อเงื่อนไขครบจะเปลี่ยนเป็น **พร้อมเริ่ม** พร้อมอนิเมชั่นคลายปมและกุญแจบนสำเนากระดาษที่เปิดอยู่ โดยไม่ขยับตำแหน่งกระดาษ โหมดลดการเคลื่อนไหวเปลี่ยนสถานะทันที

ถ้านำตราสำเร็จของใบก่อนหน้าออก เควสที่ยังไม่สำเร็จจะกลับมารอ ส่วนใบที่สำเร็จแล้วคงประวัติเดิมไว้ การลบใบก่อนหน้าจะแจ้งผลกระทบและนำใบนั้นออกจากเงื่อนไข สามารถกดเลิกทำเพื่อคืนทั้งเควสและเงื่อนไขได้ เงื่อนไขรวมอยู่ในไฟล์สำรองเดิมด้วย หลังอัปเดตกด Ctrl+F5

## หยิบเควสเป็นมัดและบรรยากาศกิลด์

เลือกเควสด้วย Shift+คลิก หรือช่องเลือกบนกระดาษ แล้วลากหัวใบที่เลือกเพื่อหยิบพร้อมกัน วางทั้งมัดบนโต๊ะ เข้าแฟ้ม หรือในลิ้นชักได้ กด Esc เพื่อยกเลิกการลากโดยไม่เปลี่ยนข้อมูล หรือกดยกเลิกการเลือกที่แถบจำนวน เอกสารที่เปิดอ่านเป็นหน้าต่างยังลากย้ายตามเดิม

เครื่องมืออื่น ๆ → บรรยากาศกิลด์ มีแสงตามเวลา/เช้า/กลางวัน/เย็น/กลางคืน/ปิด ฝุ่น และเสียงตามเวลาเครื่องที่เริ่มในโหมดอัตโนมัติ: เช้านกนอกหน้าต่าง กลางวันลมกับใบไม้ เย็นเตาผิง กลางคืนแมลงยามค่ำ เลือกฟังแต่ละช่วงเอง ปิด หรือปรับความดังเฉพาะชั้นนี้ได้ เสียงตามเวลาอิงนาฬิกาเครื่องแม้เลือกแสงเอง และค่อย ๆ เปลี่ยนผ่านประมาณ 2.5 วินาทีเมื่อไฟล์ใหม่พร้อม

ฝนกับโรงเตี๊ยมยังแยกเปิดและปรับได้ตามเดิม โดยค่าเริ่มต้นของสองชั้นนี้ปิดอยู่ ระดับเสียงบรรยากาศรวมและปุ่มปิดเสียงทั้งหมดครอบคลุมเสียงตามเวลาด้วย เสียงเริ่มหลังการคลิกหรือกดคีย์ครั้งแรก เมื่อซ่อนหน้าเว็บจะหยุดเสียงและอ่านเวลาปัจจุบันใหม่เมื่อกลับมา ลดการเคลื่อนไหวจะหยุดฝุ่นและแสงไหว ตั้งค่าเก็บในเครื่องแยกจากข้อมูลเควส

แสงอัตโนมัติอิงเวลาเครื่องที่เปิดเว็บ: เช้า 06:00–09:59 เป็นแสงทองจากด้านซ้าย กลางวัน 10:00–15:59 สว่างใส เย็น 16:00–18:59 เป็นแสงอำพันจากอีกด้าน และกลางคืน 19:00–05:59 เป็นแสงเย็นกับแสงอุ่นตามมุม มีข้อความบอกช่วงและเวลาในเมนู เลือกช่วงเองเพื่อดูแต่ละแบบได้ ฝุ่นเพิ่มจากเดิม 9 จุดเป็น 39 จุดในค่าเริ่มต้น 65% และปรับความหนาแน่นได้ 0–100% สูงสุด 60 จุด โดยจำค่าไว้หลังเปิดใหม่

แสงเช้าและเย็นปรับเป็นช่องแดดขอบฟุ้งที่อยู่นิ่ง เงาเมฆรูปร่างไม่สม่ำเสมอเคลื่อนผ่านแยกกันสองชั้นและจางก่อนเริ่มรอบใหม่ ฝุ่นจะสว่างขึ้นเมื่อผ่านช่องแดดและจางในเงา โดยใช้หน้ากากแสงเดียวกับพื้นโต๊ะ เม็ดฝุ่นยังละเอียดเท่าเดิม โหมดลดการเคลื่อนไหวคงแสงนุ่มแบบนิ่งและซ่อนฝุ่น หลังอัปเดตกด Ctrl+F5

ปรับเม็ดฝุ่นให้ละเอียดลงเหลือประมาณ 0.7–1.6 พิกเซล และใช้บรรยากาศเคลื่อนไหวช้า ๆ ตามช่วงเวลา: เงาเมฆผ่านช่องแดดเช้า/เย็น เงาเมฆนุ่มในตอนกลางวัน และแสงอุ่นไหวแยกตามมุมในตอนกลางคืน การลดการเคลื่อนไหวยังคงแสงนิ่งและซ่อนฝุ่น กด Ctrl+F5 หลังอัปเดต แล้วเลือกช่วงแสงเองในเมนูเพื่อดูแต่ละแบบ

ฝุ่นลอยวกกลับหลายทิศทางต่อเนื่อง ชั้นฝุ่นและแสงอยู่เหนือแฟ้มกับใบเควสที่วางบนโต๊ะ คลิกและลากของผ่านได้ตามเดิม ส่วนแฟ้มและใบเควสที่เปิดขยายจะอยู่เหนือบรรยากาศเพื่อให้อ่านและเขียนได้ชัด

ไฟล์เสียงบรรยากาศอยู่ใน dist/audio/ambience พร้อมที่มาใน docs/ambience-sources.md และ docs/daypart-audio-sources.md ใช้งานได้จากไฟล์ในเครื่อง หลังอัปเดตกด Ctrl+F5

เสียงโรงเตี๊ยมปรับลดความทึบและเพิ่มระดับแล้ว ความดังฝนกับโรงเตี๊ยมมีตัวเลื่อนแยกกันใต้บรรยากาศกิลด์ โดยยังมีความดังรวม ข้างชื่อเสียงแสดงสถานะโหลดและเล่นจริง หากโหลดไม่ได้ ให้ปิดแล้วเปิดเสียงชั้นนั้นเพื่อลองใหม่ได้ หลังอัปเดตกด Ctrl+F5
